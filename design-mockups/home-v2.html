Developer experience

Drop-in. Instantly.

Fully OpenAI-compatible. Point your existing SDK at EZLINK and change the model name — that's it.

  • Zero migration. Use any OpenAI SDK, unchanged.
  • Every provider, one key. No more juggling API keys.
  • Automatic failover. If a provider is down, we route around it.
  • Stream, tools, vision. Every capability works across every model. 
# Same OpenAI format. Any model.
curl https://api.ezlinkai.com/v1/chat/completions \
  -H "Authorization: Bearer $EZ_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-opus-4-7",
    "messages": [
      {"role": "user", "content": "Build me a REST API"}
    ],
    "stream": true
  }'
# Works with the OpenAI Python SDK, unchanged.
from openai import OpenAI

client = OpenAI(
    api_key="$EZ_KEY",
    base_url="https://api.ezlinkai.com/v1",
)

response = client.chat.completions.create(
    model="claude-opus-4-7",
    messages=[{"role": "user",
               "content": "Build me a REST API"}],
    stream=True,
)
// Works with the OpenAI Node SDK, unchanged.
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.EZ_KEY,
  baseURL: "https://api.ezlinkai.com/v1",
});

const stream = await client.chat.completions.create({
  model: "claude-opus-4-7",
  messages: [{ role: "user", content: "Build me a REST API" }],
  stream: true,
});
